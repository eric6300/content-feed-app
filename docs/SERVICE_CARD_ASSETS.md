# Service card image assets

The 20 service-card thumbnails are bundled under `feed/src/main/assets/service-cards/`.
Each source image was center-cropped to 640 × 288 pixels and encoded as a local JPEG so the feed stays usable offline and does not depend on a remote image host.

All images were discovered through [Openverse](https://openverse.org/) and selected from sources marked CC0 or public domain. The source links below are retained for provenance even where attribution is not required.
